# kaimere_encyclopedia
A guide to the unique science fiction world of Kaimere.


## Regions and Evolution directories

The Regions and Evolution directory pages are located in `pages/regions.html` and
`pages/evolution.html`. Both use `css/knowledge-directory.css` and
`js/knowledge-directory.js` for the shared searchable, filterable, alphabetized
directory interface.

Individual regional articles live under `regions/`; evolutionary-history
articles live under `evolution/`. Their links return to the relevant directory
and cross-link to the other section. Article text uses established Kaimere
setting details where available and explicitly leaves unspecified details open
for later worldbuilding rather than treating placeholders as canon.
